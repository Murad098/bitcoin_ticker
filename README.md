Introduction

Bitcoin Ticker is a **Flutter mobile application** that displays real-time prices of popular cryptocurrencies like **Bitcoin (BTC), Ethereum (ETH), and Litecoin (LTC)**.  

The app fetches data from the CoinGecko API and allows users to select their preferred currency (AUD, USD, EUR). It has a clean UI with coin cards and a fixed currency selector at the bottom.
